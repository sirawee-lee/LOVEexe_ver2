# Type Blast — เกมพิมพ์ดีด syntax (Cocos Creator 2.4.8)

เกมพิมพ์ดีดแบบ top-down คล้าย *Type Blast: Fast Typing Games*
ศัตรูจะลอยลงมาจากด้านบนพร้อมคำที่เป็น **syntax ของ python / html / css / js**
ผู้เล่นพิมพ์คำให้ครบเพื่อยิงทำลายก่อนที่มันจะถึงยานของเรา

## วิธีเปิด/เล่น
1. เปิดโปรเจกต์นี้ใน **Cocos Creator 2.4.8**
2. ในแผง **Assets** ดับเบิลคลิกเปิด `assets/Game.fire`
3. กดปุ่ม **Preview (▶)** มุมขวาบน เล่นในเบราว์เซอร์
4. ในเกม:
   - **คลิกที่จอ** หรือกด **ENTER** เพื่อเริ่ม / เริ่มใหม่
   - **พิมพ์ตัวอักษรแรก** ของคำเพื่อล็อกเป้า แล้วพิมพ์ให้ครบทั้งคำ (พิมพ์สัญลักษณ์ `()` `=>` `{}` ได้ในเบราว์เซอร์)
   - **Backspace** ลบตัวที่พิมพ์ผิด
   - พิมพ์ครบ = ยิงทำลาย + ได้คะแนน (มีระบบ COMBO และโชว์ **WPM** สด)

## ระบบด่าน (Level) & เกณฑ์ผ่าน
- มี **5 ด่าน** แต่ละด่านต้องเก็บคำให้ครบเป้า (เช่น 8, 10, 12...) จึงจะ **ผ่าน**
- ผ่านด่าน → **เติมหัวใจเต็ม** + ขึ้นด่านถัดไป (เร็วขึ้น, คำยาวขึ้น, เริ่มมีสัญลักษณ์)
- พลาดเก็บคำ (ปล่อยให้ตกถึงยาน) **3 ครั้ง = Game Over**
- ผ่านครบ 5 ด่าน → **BONUS CHALLENGE** โหมดไม่มีที่สิ้นสุด ไต่ความยากเรื่อย ๆ **คะแนน x2**
- จูนจังหวะให้เริ่มสบาย ๆ เหมาะคนพิมพ์ ~**35–40 WPM** (ตัวเลข WPM จะเป็นสีเขียวเมื่ออยู่ในโซนนี้)

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|------|---------|
| `assets/Game.fire` | ฉากเกม (มี Canvas + Main Camera + คอมโพเนนต์ GameManager) |
| `assets/GameManager.ts` | ตรรกะเกมทั้งหมด สร้างพื้นหลัง/ยาน/ศัตรู/HUD ด้วยโค้ด |
| `assets/WordBank.ts` | คลังคำ syntax แยกตามภาษา + สีประจำภาษา |
| `assets/resources/audio/` | เสียงเกม (สังเคราะห์เอง ไม่ติดลิขสิทธิ์): `bgm.wav` เพลงพื้นหลัง, `bgm_bonus.wav` เพลงโหมดโบนัส (เร่งเร้า), `shoot.wav` ปิ้วตอนยิงสำเร็จ, `error.wav` อื๊ดตอนพิมพ์ผิด, `key.wav` แต้กทุกตัวที่พิมพ์, `levelup.wav` ตอนผ่านด่าน |

> เสียงโหลดอัตโนมัติผ่าน `cc.resources.load("audio/...")` ไม่ต้องลากใน editor
> อยากเปลี่ยนเป็นเพลง/เสียงอื่น แค่วางไฟล์ทับชื่อเดิมใน `assets/resources/audio/`

> ทุกอย่างถูกสร้างด้วยโค้ด (Graphics + Label + RichText) จึงไม่ต้องเตรียมรูป/ฟอนต์เพิ่ม
> ใช้ฟอนต์ระบบจึงรองรับทั้งภาษาอังกฤษและภาษาไทย

## ปรับแต่งได้ง่าย ๆ
- เพิ่ม/แก้คำ: แก้ที่ `WORD_BANK` ใน `assets/WordBank.ts`
- ความยาก/จังหวะแต่ละด่าน: แก้ตาราง `LEVELS` ใน `assets/GameManager.ts`
  (`goal`=จำนวนคำที่ต้องเก็บ, `spawn`=ความถี่เกิด(วิ), `speed`=ความเร็วตก, `maxLen`=ความยาวคำสูงสุด, `symbols`=มีสัญลักษณ์ไหม)
- จำนวนหัวใจ: `LIVES_MAX` (ค่าเริ่มต้น 3)
- ความแรงโหมดโบนัส: ปรับใน `completeWord()` / `enterBonus()`
- ดีไซน์รีโซลูชัน: 720 × 1280 (แนวตั้ง) ตั้งไว้ที่ Canvas ในฉาก
